# Preeti Font

To properly view Preeti-encoded text, you need the Preeti font installed.

## Download Preeti Font

You can download the Preeti font from various sources:
- Search for "Preeti font download" online
- Check Nepali font repositories
- Government of Nepal websites

## Installation Instructions

### Windows
1. Download the Preeti.ttf file
2. Right-click on the font file
3. Select "Install" or "Install for all users"
4. Restart applications to use the font

### macOS
1. Download the Preeti.ttf file
2. Double-click the font file
3. Click "Install Font" in Font Book
4. The font is now available system-wide

### Linux
1. Download the Preeti.ttf file
2. Copy to `~/.fonts/` directory (create if doesn't exist)
3. Run `fc-cache -f -v` to refresh font cache
4. The font is now available

## Using in Applications

After installation, select "Preeti" as the font in:
- Microsoft Word
- LibreOffice Writer
- Text editors
- Design software

## Note

This project converts between Unicode and Preeti encoding. The Preeti font is required only to view Preeti-encoded text with proper Nepali characters. Unicode text displays correctly without any special font.
