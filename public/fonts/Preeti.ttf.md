# Preeti Font File

**Note:** Due to licensing restrictions, the actual Preeti.ttf font file is not included in this repository.

## How to Add the Preeti Font

1. **Download Preeti Font:**
   - Search for "Preeti font download" online
   - Download from a trusted source
   - Common sources: Nepali government websites, font repositories

2. **Add to Project:**
   - Place the `Preeti.ttf` file in this directory (`public/fonts/`)
   - The @font-face declaration is already configured in `app/globals.css`
   - The font will be automatically loaded when available

3. **Verify Installation:**
   - After adding the font file, restart the development server
   - The preview feature will display Preeti text correctly
   - Without the font, ASCII characters will be shown

## Font File Location

```
unipreeti/
└── public/
    └── fonts/
        └── Preeti.ttf  <-- Place font file here
```

## Alternative: System Font

If you have Preeti font installed on your system, the preview will use it automatically as a fallback.

## License Note
